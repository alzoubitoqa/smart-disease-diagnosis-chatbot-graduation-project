1) تجهيز البيئة الافتراضية

عرض نسخ Python الموجودة:

py -0p

إنشاء البيئة الافتراضية باستخدام Python 3.10:

py -3.10 -m venv .venv

تفعيل البيئة الافتراضية في PowerShell:

.venv\Scripts\Activate.ps1

إذا صار عندك مشكلة Execution Policy:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

تحديث pip:

python -m pip install --upgrade pip

تثبيت المتطلبات:

pip install -r requirements.txt

إذا احتجتي تثبيت الحزم الأساسية اللي استخدمناها:

pip install fastapi uvicorn tensorflow==2.13.0 python-dotenv groq passlib[bcrypt] python-jose email-validator

إذا صار تعارض bcrypt/passlib:

pip uninstall bcrypt passlib -y
pip install passlib==1.7.4 bcrypt==4.0.1
2) تشغيل واختبار طبقة الـ Knowledge Base

بناء ملفات الـ JSON من الداتا:

python src/knowledge_base/build_kb.py

أو اختبار ملف الـ knowledge base نفسه:

python src/knowledge_base/knowledge_base.py

الملفات الناتجة داخل:

artifacts/knowledge_base/

وتتضمن:

disease_descriptions.json
disease_precautions.json
symptom_severity.json
3) اختبار تحميل المودل

اختبار تحميل المودل:

python tests/test_model_load.py

إذا اشتغل لازم يطبع:

Model loaded successfully
4) تشغيل الـ Backend الحالي

الأمر الصحيح الحالي لتشغيل الـ backend:

python -m uvicorn src.api.main:app --reload

وليس:

uvicorn src.api.api_main:app --reload

لأن الملف الحالي عندك هو:

src/api/main.py

بعد التشغيل:

Swagger:
http://127.0.0.1:8000/docs
5) أهم Endpoints الموجودة حاليًا في الـ Backend
Authentication
Register:
POST /api/auth/register
Login:
POST /api/auth/login
Profile
Read profile:
GET /api/profile/{user_id}
Update profile:
PUT /api/profile/{user_id}
Symptoms
Get dataset symptoms:
GET /api/symptoms
Prediction
Basic prediction:
POST /api/predict
History-aware prediction:
POST /api/predict/history-aware

7) تشغيل الـ Frontend الحالي

من داخل مجلد الفرونت:

cd disease-chatbot-frontend

تثبيت الحزم:

npm install

تشغيل الواجهة:

npm run dev

واجهة الفرونت تفتح غالبًا على:

http://localhost:5173
