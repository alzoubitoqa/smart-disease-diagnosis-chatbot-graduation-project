# DiagnoSeq

DiagnoSeq is an AI-powered disease prediction system that analyzes sequential symptom data using deep learning models, including Simple RNN, Vanilla LSTM, and Stacked Deep LSTM.

## Project Structure
- data/: raw and processed datasets
- src/: preprocessing, models, training, evaluation, inference, and app
- artifacts/: trained models and reports
- outputs/: generated figures and prediction outputs

## Models
- Simple RNN
- Vanilla LSTM
- Stacked Deep LSTM

## Interface
A simple Streamlit interface is used for disease prediction, disease description, and precautions.
