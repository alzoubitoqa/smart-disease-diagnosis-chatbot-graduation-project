المشكلة لأنكِ على **PowerShell**، و`/Q` و`del` بالطريقة هاي تبعت **CMD** أكثر، فـ PowerShell عم يفسّرها كـ `Remove-Item` وما بيعرف `/Q`.

استخدمي هاي الأوامر بدلها داخل **PowerShell**:

## حذف ملفات `models`

```powershell
Remove-Item .\artifacts\models\* -Force
```

أو فقط ملفات `.keras`:

```powershell
Remove-Item .\artifacts\models\*.keras -Force
```

## حذف ملفات `processed`

```powershell
Remove-Item .\artifacts\processed\* -Force
```

لكن لأن عندك مجلد داخلي `knowledge_base`، استخدمي:
Remove-Item .\artifacts\knowledge_base\* -Force


```powershell
Remove-Item .\artifacts\processed\* -Recurse -Force
```

## حذف ملفات `reports`

```powershell
Remove-Item .\artifacts\reports\* -Recurse -Force
```

## حذف قاعدة البيانات

```powershell
Remove-Item .\artifacts\db\* -Force
```

Remove-Item .\artifacts\figures\* -Force


---

## لو بدك تنظيف كامل لـ `artifacts` ثم إعادة إنشائه

هذا أقوى حل:

```powershell
Remove-Item .\artifacts -Recurse -Force
New-Item -ItemType Directory -Path .\artifacts
New-Item -ItemType Directory -Path .\artifacts\db
New-Item -ItemType Directory -Path .\artifacts\models
New-Item -ItemType Directory -Path .\artifacts\processed
New-Item -ItemType Directory -Path .\artifacts\processed\knowledge_base
New-Item -ItemType Directory -Path .\artifacts\reports
```

---

## إذا طلع خطأ لأن المجلد فاضي

هذا عادي.
ولو بدك أمر آمن أكثر وما يوقفك على الأخطاء:

```powershell
Remove-Item .\artifacts\models\* -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item .\artifacts\processed\* -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item .\artifacts\reports\* -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item .\artifacts\db\* -Recurse -Force -ErrorAction SilentlyContinue
```

---

## الأفضل إلك الآن

بما إنك بدك تبدأي من جديد، انسخي هذا كله مرة وحدة:

```powershell
Remove-Item .\artifacts -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path .\artifacts
New-Item -ItemType Directory -Path .\artifacts\db
New-Item -ItemType Directory -Path .\artifacts\models
New-Item -ItemType Directory -Path .\artifacts\processed
New-Item -ItemType Directory -Path .\artifacts\processed\knowledge_base
New-Item -ItemType Directory -Path .\artifacts\reports
```

بعدها اعملي:

```powershell
tree .\artifacts
```

ولازم يطلع عندك فقط المجلدات فاضية.

إذا بدك، أرتب لك مباشرة **شو نشغل بعد التنظيف خطوة بخطوة** حتى نرجع نبني الـ preprocessing ثم augmentation ثم training من الصفر.
